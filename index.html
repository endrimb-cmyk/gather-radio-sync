Акаунт та доступ

Слухачі входять без акаунта. Тільки власник ефіру входить через Google, щоб обирати музику.

Гість

Google-вхід зберігається в цьому браузері до виходу (якщо не очищати дані сайту). YouTube API може попросити повторно підтвердити доступ до каталогу після перезавантаження.

Створити спільний ефір

Увійди через Google, створи кімнату, а потім додай її адресу в Interactive Object у Gather. Усі охочі зможуть приєднатися.
